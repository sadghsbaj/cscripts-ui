# Pricing / Plan Picker

*Type: Compound pattern*

## Layout Plan

Few options, equal weight, one gently recommended. Comparison detail is secondary.

**Placement**
- Billing period toggle centered above
- Three plan columns of equal width
- Price largest, one-line summary, short feature list, one action each

**Progressive disclosure / restraint**
- Max four features per plan; full comparison behind 'Compare all'
- Recommended plan marked by a single badge
