# Task List

*Type: Compound pattern*

## Layout Plan

A plain vertical list with generous rows; the status word is the only varying accent.

**Placement**
- Checkbox, title, then right-aligned status
- Counter in the header
- Completed items sink visually, not physically

**Progressive disclosure / restraint**
- Secondary meta (date, assignee) visible on hover or focus
- Completed section collapsible

---

## Wireframe

```text
 Today                             2 of 5 done
 +--------------------------------------------+
```
