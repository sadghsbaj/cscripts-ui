# Tag / Recipient Input

*Type: Compound pattern*

## Layout Plan

The field behaves like one box; chosen entries live inside, suggestions float below.

**Placement**
- Label above, field full width
- Chosen entries as small badges inline, caret after them
- Suggestion list anchored to the field

**Progressive disclosure / restraint**
- Suggestions only after typing starts
- Max 5 suggestions, rest via scroll
- Helper text shown only on focus
