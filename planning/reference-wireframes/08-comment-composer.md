# Comment Composer

*Type: Compound pattern*

## Layout Plan

Looks like a single text surface; tools sit in a thin footer so writing stays the focus.

**Placement**
- Textarea grows with content
- Footer: tools left, hint and send right
- Avatar to the left outside the surface

**Progressive disclosure / restraint**
- Formatting tools collapsed into one menu
- Keyboard hint appears only on focus
- Send disabled until text exists

---

## Wireframe

```text
 (o)  +----------------------------------------+
      | Write a comment...                     |
      |                                        |
      |----------------------------------------|
      | [+] [:)]            Ctrl+Enter [Send]  |
      +----------------------------------------+
```
