# Number Stepper Toolbar

*Type: Compound pattern*

## Layout Plan

A compact floating toolbar; the value is the visual center, controls flank it.

**Placement**
- Minus, value, plus in one tight group
- Reset as a quiet text action to the side
- Size steps as a small segmented control, separated by a divider

**Progressive disclosure / restraint**
- Reset visible only when the value differs from default
- Keyboard hints shown in a tooltip, not inline

---

## Wireframe

```text
+------------------------------------------------+
|  [ - ]  [ 125% ]  [ + ]  |  (S | M | L)  Reset |
+------------------------------------------------+
```
