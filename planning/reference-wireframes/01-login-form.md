# Login Form

*Type: Compound pattern*

## Layout Plan

A single narrow column with one clear path. Nothing competes with the primary action.

**Placement**
- Title and one-line hint on top
- Two fields stacked, equal width
- Remember-me and the secondary link share one quiet row
- Primary action full width, secondary text-level below

**Progressive disclosure / restraint**
- Error text appears only under the failing field
- Alternative sign-in methods collapsed behind one link
- No decorative content
