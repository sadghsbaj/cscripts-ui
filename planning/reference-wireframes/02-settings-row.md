# Settings Row

*Type: Compound pattern*

## Layout Plan

Text left, control right, always the same rhythm. Rows are grouped by a shared surface, not individual borders.

**Placement**
- Label with one-line description on the left
- Control aligned to the right edge
- Group title above, thin dividers between rows

**Progressive disclosure / restraint**
- Descriptions short; long help moves into a tooltip
- Dependent options appear only when the parent switch is on
