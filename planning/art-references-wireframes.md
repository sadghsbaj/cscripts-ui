# Art References – Wireframe Plan

Companion to [art-references-ideas.md](art-references-ideas.md). Each idea has its own file in `reference-wireframes/`: an English layout rationale on top, an ASCII sketch below. No colors or exact measurements; only placement and structure.

## Shared layout principles

1. **One focus per view.** A single primary action or content area dominates.
2. **Calm density.** Generous spacing, grouping by shared surfaces instead of many borders.
3. **Progressive disclosure.** Secondary controls, help, and rare options appear on demand (hover, focus, expansion, or a menu).
4. **Aligned structure.** Labels left, controls right; consistent column and row rhythm.
5. **State without clutter.** Errors, dirty state, and filters appear only when relevant.
6. **Overlays stay small.** Modals and popovers are for one decision, never for browsing.
